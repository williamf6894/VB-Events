## Objective

A simple event management platform

### Backend (API)

- CRUD for Events
- CRUD for Participants
- Read for all events
  - with filters by date, status, past/future, etc
- Health Check
- Database (Postgres)

### Frontend

- List of all events
- Event details
  - List of all Participants 
  - Register new Participant
  - Clear feedback on 
    - if an event is full
    - bad input
    - etc

### Techology

- Go (backend)
- Svelte (frontend)
- Postgres (database)
